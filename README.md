# Rusky

Application personnelle pour préparer le ТРКИ-1 (B1 de russe) : 3 leçons par jour (révisions, texte
avec les mots connus, texte avec 10 mots nouveaux), lecteur analysé, progrès vers chaque niveau.

- Code : [`rusky-b1/`](rusky-b1/) (Next.js 16, Prisma + Turso). Déploiement : `git push` sur `main`
  (projet Vercel « russky », dossier racine `rusky-b1`).
- Ancienne version : archivée dans `.ancienne-app/` (voir son README).
